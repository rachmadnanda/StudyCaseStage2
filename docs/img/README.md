# Tangkapan Layar Pengujian

Berkas tangkapan layar disimpan pada folder ini dengan nama berikut, lalu dirujuk dari
laporan.

| Kode | Berkas | Isi |
|---|---|---|
| SS-01 | `SS-01-wiring.png` | Rangkaian lengkap Wokwi |
| SS-02 | `SS-02-serial-aman.png` | Serial Monitor kondisi AMAN |
| SS-03 | `SS-03-serial-bahaya.png` | Serial Monitor kondisi BAHAYA |
| SS-04 | `SS-04-oled-kritis.png` | OLED KRITIS (pita dibalik dan bar penuh) |
| SS-05 | `SS-05-hivemq.png` | Payload diterima HiveMQ Web Client |
| SS-06 | `SS-06-dashboard.png` | Dashboard Python menampilkan grafik |
| SS-07 | `SS-07-csv.png` | Isi berkas CSV hasil logging |
| SS-08 | `SS-08-offline.png` | Status offline (uji LWT) |
| SS-09 | `SS-09-oled-panas.png` | OLED menampilkan flag lingkungan `PANAS` |

Format berkas adalah PNG agar teks Serial Monitor tetap tajam. Pada Windows, tangkapan
layar dapat diambil dengan `Win + Shift + S`; pada Linux dengan `gnome-screenshot -a`.
